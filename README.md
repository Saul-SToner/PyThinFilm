# PyThinFilm：基于 Python 的薄膜光学仿真、设计与教学平台

面向波动光学学习、薄膜结构设计与数值复验的开源项目，也是 2026 年全国大学生物理实验竞赛创新赛自选课题类作品的开发仓库。

项目以传输矩阵法（TMM）为基础，将薄膜结构、光谱响应、反射相位与层内电场联系起来，帮助学习者从公式推导走向可操作、可比较、可复算的虚拟实验。平台包含 Python 计算库和 Windows 桌面端，并保留光栅波导、界面光学与辐射制冷等研究拓展。

本文按照[作品说明书](work_instruction_book_cleaned.md)的项目逻辑编写；功能范围与实现状态以当前源码和验收记录为准。

## 一、项目背景

薄膜干涉广泛应用于镜头增透、激光反射镜、光通信滤波器和光谱选择性涂层。在本科波动光学教学中，学生通常先学习单界面菲涅尔公式和单层膜干涉；当膜层增加、材料具有色散或入射角变化时，公式与实际光谱之间的联系更难直观理解。

实体制膜与光谱测量又受到设备、材料和实验课时的限制。PyThinFilm 因此以可查看的计算过程和可重复的参数实验，补充理论教学与实体实验：改变一个参数，观察光谱变化，再用相位、场强和能量关系解释结果。

## 二、项目目标与教学思路

平台面向波动光学课程学习者、实验教学教师，以及需要进行平面膜系初步分析的使用者，围绕三项目标展开：

1. **理解物理规律**：把菲涅尔反射、多光束干涉、四分之一波光学厚度和腔共振转化为可观察的曲线与场分布。
2. **开展控制变量实验**：调节膜厚、材料、周期数、波长、入射角和偏振，比较结构变化对光学响应的影响。
3. **建立验证意识**：结合解析基线、独立求解器与外部数据，检查单位、材料来源、守恒关系和模型适用范围。

桌面端的引导实验采用“预测 → 修改参数 → 仿真观察 → 曲线比较 → 记录结论”的流程，将物理规律进一步连接到膜系功能、应用场景和设计任务。

## 三、理论基础与计算方法

### 3.1 平面多层膜传输矩阵法

TMM 根据各界面切向电磁场连续条件，将膜层特征矩阵依次级联，计算平面层状结构的反射、透射和吸收响应。平台支持 TE/s、TM/p 偏振以及斜入射计算，并提供反射与透射相位、层内一维电场强度等教学分析。

| 物理量 | 含义 | 主要观察问题 |
| --- | --- | --- |
| R、T、A | 反射率、透射率、吸收率 | 能量流向如何随结构和波长变化？ |
| n、k | 折射率、消光系数 | 色散与损耗如何改变理想膜系？ |
| nd | 光学厚度 | 相同物理厚度为何产生不同干涉结果？ |
| 反射/透射相位 | 复振幅的相位 | 相位变化与共振特征如何联系？ |
| 层内相对电场强度 | 一维空间场分布 | 驻波和场增强出现在哪里？ |
| FWHM、Q | 峰宽与品质因子 | 如何量化谱峰的选择性？ |

对于适用能流定义下的无源膜系，检查 R + T + A = 1；其中 A 由能量差计算时，还需结合独立对照与非负性检查判断结果，不能仅凭代数闭合证明求解正确。

### 3.2 真实材料与色散

材料模块读取离散 n/k 数据，插值到目标波长网格，并通过缓存减少重复读取。默认限制超出材料数据范围的外推，使理想常数折射率模型与真实色散材料能够在一致条件下比较。

### 3.3 光栅与外部数据

研究支线保留亚波长有效介质近似（EMT）与 COMSOL CSV 导入、扫描参数筛选、峰位和线宽提取等功能。EMT 只用于其适用的亚波长近似范围；当前桌面端光栅教学入口使用可选外部 RCWA 后端进行在线计算。两条计算路径的物理含义需分别解释。

## 四、平台功能与案例体系

### 4.1 自由膜系设计

Windows 桌面端提供膜层编辑、真实材料选择、波段和入射条件设置，以及 R/T/A 曲线和 Three.js 三维结构展示。使用者可以查看相位、光学厚度与探针波长处的一维场强，记录实验结果，并叠加历史光谱进行比较。

### 4.2 基础教学案例

| 案例方向 | 核心问题 |
| --- | --- |
| 单层与多层减反膜 | 折射率匹配和光学厚度如何抑制反射？ |
| 四分之一波与半波膜 | 相位积累如何影响界面反射的叠加？ |
| Bragg 高反膜与周期堆 | 周期数和折射率差如何影响高反带？ |
| F-P 与窄带滤光片 | 腔层厚度与镜面结构如何改变透射峰？ |
| 渐变折射率与多孔等效层 | 连续或离散折射率匹配如何改变光谱？ |
| 中性分束膜 | 如何观察反射与透射的能量分配？ |

当前 App 默认公开 **22 例**：18 个基础薄膜教学案例、1 个 RCWA 光栅实验和 3 个 Ag/DBR 教学实验。完整开发目录保留 **40 例**，其余 18 例归档，App 不提供归档显示开关。公开范围由 `Frontend/V3/backend/app/case_release.py` 定义，详见[教学发布范围](docs/APP_RELEASE_SCOPE.md)。

### 4.3 工程应用与研究拓展

仓库保留太阳能电池减反膜、WDM 滤波器、激光镜、镜头减反膜和节能窗膜等应用方向，以及 Tamm、PDRC 和光栅波导研究资料，用于讨论从物理模型到器件指标的联系。

这些方向具有不同成熟度：部分工程目标尚未达成或完整应用尚未验证，当前归档保留，不作为已完成器件公开展示。3 个公开 Ag/DBR 实验采用 GeneralTmm 平面教学模型，需结合反射、相位、吸收与场分布判断，不能单凭谱峰或谱谷确认界面态，也不代表历史 COMSOL 结构已被复现。

### 4.4 系统分析与动画资料

Optiland 集成用于透镜、镜面和等效分光面等系统级追迹与分析，帮助连接膜系响应和系统中的能量分配。其结果应按各模板已验收的观察量解读。

平台还提供可重算的动画生成脚本，覆盖薄膜干涉机制、膜厚扫描、Bragg 周期数、F-P 腔层变化、场分布及系统应用。无配音原片和串联预览用于审阅与后期制作，正式参赛成片仍需教学解释、配音和节奏编排。

## 五、项目特色与教学价值

- **物理过程可追溯**：从膜层结构到光谱、相位与场分布，计算核心和数据处理过程可查看。
- **教学与设计结合**：基础案例、自由膜系设计、实验任务和历史曲线比较支持连续的探究流程。
- **理想模型与真实材料对照**：将折射率匹配等理想规律与真实色散、吸收联系起来。
- **多路径验证**：结合解析基线、独立求解器、自动化测试和外部证据检查结果。
- **从薄膜到系统**：通过适用范围明确的 Optiland 教学模板，探索膜系响应在光学系统中的作用。

这些是项目的实现特色与设计目标；学习效果仍需通过实际课堂使用与反馈评估。

## 六、软件架构

```text
PyThinFilm/
├── thinfilm/                 # TMM、材料、教学 API、验证及专用求解器适配
├── guided_grating/           # 光栅研究、外部扫描数据导入与分析
├── Frontend/V3/
│   ├── frontend/             # Electron + React + TypeScript 桌面界面
│   └── backend/              # FastAPI 本地服务与案例封装
├── cases/                    # 教学与专题运行入口
├── examples/                 # 工程应用示例
├── data/                     # 材料与参考数据
├── tests/                    # Python 核心测试
├── experiments/              # Optiland 集成实验与系统模型
├── tools/                    # 数据导出、发布验收与动画工具
├── web3d/                    # 网页三维教学原型与案例数据
└── docs/                     # 发布范围、验证记录与素材说明
```

桌面端通过 FastAPI 调用计算能力，物理逻辑使用仓库根目录的 `thinfilm/`。`Frontend/V3/PyThinFilm/` 为本地历史副本，不参与开发运行或打包。

| 组件 | 当前职责 |
| --- | --- |
| PyThinFilm | Python 物理核心、教学洞察与独立复验 |
| tmmcore | 桌面端主要平面膜 R/T/A 光谱路径 |
| RCWA | 周期光栅的专用计算 |
| GeneralTmm | 平面 Ag/DBR 等专用教学计算 |
| WPTherml | 可选热辐射相关计算 |
| Optiland | 系统级几何追迹与分析 |

前端对接可从 `thinfilm/api.py`、V3 后端接口及生成的 `~/thinfilm_outputs/teaching_main_branch_catalog.json` 开始。详细接口见[V3 桌面端说明](Frontend/V3/README.md)。

## 七、安装与使用

### 7.1 Python 教学脚本

在项目根目录安装基础依赖并运行：

```powershell
python -m pip install -r requirements.txt
python smoke_test.py
python run_teaching_demo.py --list
python run_teaching_demo.py --case single_ar
```

教学输出默认保存到 `~/thinfilm_outputs/`。不同专题和专用后端可能需要额外依赖。

光栅支线支持外部扫描数据筛选，例如：

```powershell
python run_guided_grating_demo.py --sweep-csv "path/to/2d.csv" --target-wavelength 1550
```

### 7.2 Windows 桌面端开发

```powershell
cd Frontend/V3
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
cd frontend
npm ci
npm run dev
```

专用求解器与 Optiland 的环境配置见[V3 说明](Frontend/V3/README.md)和[发布依赖清单](tools/release-dependencies.json)。外部 Optiland checkout 不包含在本仓库中，发布构建需要按清单准备。

### 7.3 Windows 打包

在 `Frontend/V3/frontend/` 执行：

```powershell
npm run typecheck
npm run dist
npm run release:smoke
```

发布流程包含依赖预检、PyInstaller 后端、GeneralTmm 独立嵌入式运行时，以及 Electron 安装版和便携版。源码仓库不提交生成的安装包、视频与本地运行时。验收范围见[Windows 打包审计](docs/PACKAGING_AUDIT_20260923.md)。

## 九、适用范围与后续计划

TMM 核心面向平面一维层状介质；复杂粗糙表面、任意三维结构等问题需使用适合的电磁模型。EMT 与 RCWA 的计算范围不同，COMSOL CSV 导入只负责已有结果的读取与分析。层内一维场分布、三维结构示意和几何光线追迹也分别对应不同物理含义。

教学平台不提供厚度反演入口，旧反演样本 CSV 不保留在仓库。归档研究案例重新开放前，需要明确教学问题、输入来源、物理模型和评价指标，并完成结果与界面流程复验。

后续工作主要围绕基础教学体验、原始数据复现、独立物理验证与新 Windows 设备发布验收展开；工程应用和研究拓展按各自证据成熟度逐项推进。
