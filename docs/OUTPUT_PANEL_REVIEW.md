# 40 例输出面板检查

已逐例调用实际输出入口：18 个实时 TMM 案例、9 个专用求解器案例、13 个结果/证据案例。全部 HTTP 200，返回非空曲线，每条 x/y 长度一致且数值有限。明细见 `Frontend/V3/backend/outputs/output_panel_data_audit.json`。

本轮修复共用输出面板：

- 计算中显示加载状态，不继续显示上次结果；错误直接显示在输出面板。
- 计算/带入期间禁止切换案例，避免异步旧结果污染新案例。
- 切换案例恢复曲线标签，避免从膜层/图片页切入专用案例时出现空白。
- 指标标题和值允许换行，减少长文截断。
- 补充工程案例的中文指标和波长单位。

沿用前轮修复：静态光谱默认只显示 TE 一套，可切换 TM 或显式比较；去掉独立 R/T/A 图片的重复入口；历史证据适用范围单独折叠。

本轮验证覆盖数据合同与源代码路径，前端构建及类型检查通过。没有逐例完成浏览器截图验收，不能以数据可绘制断言所有视觉问题已消失；其它历史字段的专业翻译、混合量纲图和全部窗口尺寸仍需视觉核验。
