# Stage C.V1A：太阳电池减反膜视觉原型人工复核

## 1. 复核对象与方法

对象：`app_solar_cell_ar` 的独立 Vite/Three.js 页面 `/apps/solar-ar/`，以及用于隔离回归的通用案例浏览器 `/`。

方法：

1. Playwright 启动真实 Chromium，执行 `stage_cv1a_visual_runtime.spec.js`；
2. 分别切换低反射/550 nm/相对高反射、等轴剖视、侧面剖视、光路视角和 TE/TM，保存七张全页截图；
3. 打开同一 localhost 页面，检查独立 DOM、按钮行为、HUD 和浏览器 console；
4. 单元测试校验材料颜色、厚度映射、相机预设和层交互外观；
5. 不使用截图像素完全一致作为判据。

## 4. 行为与回归检查

自动化检查覆盖：

- 颜色映射稳定、未知材料哈希稳定、介质 metalness 为 0；
- 厚度映射单调、有上下界；
- 三个相机预设有效且没有 TOP_VIEW；
- 重置视角返回 `ISOMETRIC_SECTION`；
- 三层 mesh 可加载，选中/取消有效；
- 动态波持续播放，暂停后时间停止，恢复后继续；
- 独立 solar App 的 renderer 实例数保持 1；
- 通用案例浏览器仍可单独加载 `app_solar_cell_ar`，且没有独立 solar App 的控制 DOM；
- 低反射、550 nm 和相对高反射状态均直接读取正式 JSON，R/T 振幅绑定不变；
- 页面 console 和 page error 均为空；
- 原 R/T 选点振幅、TE/TM 正交基和波生命周期测试继续通过。

## 5. 已知限制

1. 原型是独立 App，只作用于 `app_solar_cell_ar`；其他案例尚未统一到公共视觉模块。
2. `LineBasicMaterial.linewidth` 在部分 WebGL 平台固定为 1 像素；当前设计以颜色、透明度和方向箭头保证可读性。
3. 厚度为非线性视觉映射，不能从屏幕比例反推纳米厚度；真实值以标签为准。
4. “展开/叠合”会引入教学性的视觉间距，默认叠合状态没有真实间隙。
5. 动态波仍是选中光谱点 R/T 驱动的教学示意，不是空间定量电场。三种波统一使用 `2.2` 的显示尺度；极小非零反射仍受最小可见值规则放大，并在页面标记。
6. 正式 JSON 的 550 nm 附近 R 约为 41.01%，不是清晰的减反点；因此默认展示正式数据中的最小 R 点。所谓“相对高反射”也只表示本案例扫描区间内 R 最大，不能解释为高反镜或相对裸 Si 的增反。
7. 当前正式工程 JSON 只有现有离线光谱切片；前端没有新增角度计算、热力图或场求解。

## 6. 人工结论

Stage C.V1A 已达到“独立 App、低饱和蓝灰白、浅色学术科研可视化、层序清晰、波形差异可判读”的原型目标，并守住正式结构、物理绑定、renderer 和资源生命周期边界。人工检查请从 Vite 服务打开 `/apps/solar-ar/`，重点比较“低反射”和“相对高反射”、三种相机视角、标签遮挡及 hover/selected 强度；不要直接双击 `index.html`。未获人工确认前不推广到其他案例。
