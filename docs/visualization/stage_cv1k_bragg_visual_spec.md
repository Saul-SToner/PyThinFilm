# Stage C.V1K Bragg 单案例视觉原型规格

## 目标

在冻结教学语义上，为 `bragg_reflector` 建立本科实验教学取向的逐案例视觉叙事。该阶段不推广到其他案例。

## 正式结构标注

七层正式结构保持：

```text
H / L / H / L / H / L / H
```

视觉分组采用：

```text
周期 1：H/L，第 1–2 层
周期 2：H/L，第 3–4 层
周期 3：H/L，第 5–6 层
终止层：H，第 7 层
```

不得把七层描述为四个完整周期。三维括号和底部按钮只表达正式结构分组，不代表场叠加或反射贡献的定量分解。

## H/L 图例

- H 使用现有固定高折射率材料色；
- L 使用现有固定低折射率材料色；
- 图例不修改材料、不覆盖原始层颜色；
- 层厚仍采用既有单调视觉映射。

## 正式 TE/TM 对照

同一当前波长下，同时从正式 JSON 光谱读取并插值：

```text
TE 反射率 R_TE
TM 反射率 R_TM
差值 R_TE - R_TM
```

该卡片只用于显示 45° 入射下的正式偏振分裂，不重新运行 TMM，也不把差值解释为独立物理量。

## 双状态

- 阅读解释：显示完整冻结教学抽屉；
- 观察模型：抽屉缩为状态条，保留当前步骤和正式状态；
- 切换不改变波长、偏振、选中层、相机、Canvas 或 Renderer。

## 冻结边界

不得修改：

- 七层正式层序、厚度与正式 JSON；
- 45° 入射和 TE/TM 光谱；
- 五步教学契约；
- 正弦波传播与振幅规则；
- Python TMM；
- F-P、单层减反和 Tamm 案例。
