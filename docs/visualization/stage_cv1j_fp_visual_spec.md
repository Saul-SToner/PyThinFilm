# Stage C.V1J F-P 单案例视觉原型规格

## 目标

在已冻结的本科教学语义基础上，为 `fp_filter` 建立本科实验教学取向的逐案例视觉叙事。该阶段不推广到其他案例。

## 视觉选择

- 风格：本科实验教学，保持低饱和蓝灰白和学术克制；
- 教学面板：提供“观察模型 / 阅读解释”双状态；
- 结构标注：允许显示正式层序分组，但不得表达定量场强。

## F-P 专属结构叙事

正式 13 层保持不变，视觉标注分为：

```text
入射侧 DBR：第 1–6 层
中央缺陷腔：第 7 层
基底侧 DBR：第 8–13 层
```

第 7 层增加克制的结构描边和随相机投影更新的标签。描边与标签只表示结构角色，不代表腔内场增强、模态分布或能量密度。

## 双状态行为

### 阅读解释

- 显示完整教学抽屉；
- 保留五步引导、正式证据字段和公式折叠内容；
- 不改变既有教学契约。

### 观察模型

- 教学抽屉缩为状态条；
- Three.js 场景和结构分组获得更大可视区域；
- 当前步骤、波长、偏振、选中层及正式 R/T/A 保持不变；
- 不创建新的 Canvas、Renderer 或场景。

## 冻结边界

本阶段不得修改：

- `fp_filter` 正式 JSON 数值及 13 层层序；
- 缺陷模与全谱最大透射点的既有语义区分；
- 五步教学任务及证据绑定；
- Python TMM、R/T/A 插值和正弦波振幅/传播公式；
- 其他三个冻结教学案例的视觉和逻辑。
