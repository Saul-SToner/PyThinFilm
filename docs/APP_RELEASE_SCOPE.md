# App 教学发布范围

App 默认案例列表现在公开 22 例：18 个基础薄膜教学案例、1 个 RCWA 光栅实验入口及 3 个恢复的 Tamm 教学实验。

隐藏 5 个工程应用及 13 个研究拓展入口。此前整体隐藏研究拓展过于粗略，现恢复 `tamm_interface_priority`（偏振反射）、`tamm_phase_bundle`（反射相位）、`tamm_phase_focus`（吸收与场分布）。三者的 App 名称和说明基于当前平面 Ag/DBR GeneralTmm 实验；不显示旧棱镜 Optiland 草案，不读取历史证据作为本次计算结果。其它候选筛选、重复相位筛选及窗口条目继续归档。

太阳能和手机案例的目标未达成；WDM、激光、Low-E 的完整应用尚未验证。不把这些条目临时改名为失败分析案例后继续公开。

隐藏不等于删除：原始数据、求解器、案例详情、开发验收能力保留。`/api/case-library?include_archived=true` 可供开发检查原 40 例，App 不提供这个开关。公开数量由后端过滤后的列表统计，不再写死 40。

保留的 19 例也只按基础教学范围解释：高反膜连接单镜基线，不代表激光腔；中性膜连接零厚度等效分光面；EMT 命名入口的在线计算为 RCWA。复杂工程模型仍遵守已有验收边界。

重新开放要求：明确教学问题、物理模型与输入来源、正确量纲和指标、结果与结论一致、界面工作流复验通过。若作为失败方案教学，需要单独编写问题、对照和原因分析，不能用免责声明代替教学设计。
