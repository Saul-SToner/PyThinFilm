# 反射、分光、匹配鬼像：实现与限定范围复验

2026-09-20。本轮在当前 App 实时渲染路径上实现三项原生 NSQ 基线。它们通过下列数值验证，不表示完整激光谐振腔、厚基片分光器或偏振杂散光系统已完成。

## 当前行为

- 反射族进入原生 NSQ 平面镜：按当前膜系、波长、入射角计算无偏振 R，用真实镜面反射方向追迹到接收面。UI 明确标记单镜反射，激光腔和扩束模板名称不会被当作腔模型已实现。
- 中性分光案例进入原生 NSQ 双支路：同一次追迹在零厚度等效分光面分成反射与透射两支路，两个探测器分别记录功率。两支路确定性分裂，因此不是分别抽样后拼接两个结果。
- 成像鬼像逐面读取同一已调焦 optic/spec 的位置、曲率、材料与口径；包括吸收边缘、40×40 mm 接收面、当前视场源。顺序与非顺序共享明确口径（清孔直径为 EPD 的 1.4 倍）。不再以固定 N-BK7 单片代替多片镜头。
- 镀膜从 TMM 计算当前波长、入射角分箱的无偏振 R/T；逆向入射交换介质并反转膜层顺序。0.5° 分箱为近似，已与 0.25° 对照。
- 鬼像由实际表面交互的入/出方向相对法线符号判断反射，按 ray_id 累计反射事件；到达接收面且有反射事件的功率计为鬼像。不再使用两张图相减并截断负值。
- Ghost 卡片默认折叠，展示射线数及功率标准误差。基准鬼像不足三倍标准误差时不报告抑制比。
- 每个后端渲染请求使用独立目录，解决图片被后续案例覆盖及缓存串图的问题。

## 验证证据

运行 `../optiland/.venv/Scripts/python.exe experiments/validate_engineering_nsq.py`，结果写入 `Frontend/V3/backend/outputs/engineering_nsq_validation.json`。

1. 八组常数 R/T 光路：法向与 45°，镜面/双路，50/50 和 R=0.8、T=0.15。反射方向符合矢量反射定律，接收功率误差 <1e-9 W。
2. 实际 MgF2/N-BK7 在 550、1064、1550 nm、45° 的双路功率与 TMM R/T 相符（<1e-9 W）。
3. 单透镜、手机、复杂镜头、18° 宽视场四类鬼像：逐面数量与 spec 一致；直接光与顺序追迹通光量在五倍估计标准误差加 0.001 W 容差内相符。
4. 每类检查深度 24→32；射线数 20000→40000，并更换随机种子；角度分箱 0.5°→0.25°。鬼像差异在合并五倍标准误差 +1e-5 W 内，总接收功率差异在合并五倍标准误差 +0.001 W 内。深度截断损失 <0.001 W。此为工程回归阈值，不代表严格五西格玛统计置信结论。
5. 实际后端 `/api/optiland/system` 分别执行反射、分光和单透镜匹配鬼像；全部返回 ready，所有图片 URL 可读取有效 PNG。2D 双支路、匹配鬼像图已视觉检查。
6. 既有 18 项 Optiland 集成测试、43 项后端测试和前端构建通过；先前成像/窗口数值基线仍通过。

## 功率预算的解释

外部 NSQ 的原始账本没有计入标量镀膜损耗。平面支路测试独立按入射 1 W 计算已知损耗：镜面 1−R（未反射损失），分光面 1−R−T；保留原始账本，同时返回计入这项损耗的残差。没有把镜面未反射能量擅自称为纯吸收。

鬼像采用反射概率 0.1 的重要性采样并补偿路径权重，报告标准误差；因此单次样本的总功率账本可出现统计起伏，不能把该偏差当作确定性求解器能量残差。未为任意吸收材料建立完整逐面吸收预算。本轮鬼像验收限于已测试的透明 N-BK7 基底和 MgF2 膜。

## 模型边界

- 单镜基线不是激光腔往返反馈或扩束系统；UI 已标明。
- 分光面是空气中零厚度功率等效元件，不包括真实基片厚度、横向位移及基片背面反射。
- 匹配鬼像为同轴球面镜片、空气环境、单色无偏振几何光学；不含散射粗糙度、机械筒壁、相干叠加、偏振跟踪。固定接收面宽度与有限孔径均记录在结果中。
- 40 个案例的工程入口覆盖和全部材料组合不在本轮全面验收范围内；现有禁止自由设计的证据案例仍不应宣称已接通新模型。
